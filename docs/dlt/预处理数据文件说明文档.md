# 预处理数据文件说明文档

## 1. draws.parquet

`draws.parquet` 保存大乐透每一期开奖数据与号码基础特征数据

| 字段                        | 类型   | 必填 | 说明                                        |
| --------------------------- | ------ | ---- | ------------------------------------------- |
| issue                       | string | 是   | 开奖期号，例如 `26107`                      |
| draw_date                   | date32 | 是   | 开奖日期                                    |
| draw_result                 | string | 是   | 官方开奖字符串，例如 `02 05 07 14 22 04 10` |
| red_1                       | int32  | 是   | 前区第 1 个号码                             |
| red_2                       | int32  | 是   | 前区第 2 个号码                             |
| red_3                       | int32  | 是   | 前区第 3 个号码                             |
| red_4                       | int32  | 是   | 前区第 4 个号码                             |
| red_5                       | int32  | 是   | 前区第 5 个号码                             |
| blue_1                      | int32  | 是   | 后区第 1 个号码                             |
| blue_2                      | int32  | 是   | 后区第 2 个号码                             |
| red_sum                     | int32  | 是   | 前区号码和值                                |
| red_span                    | int32  | 是   | 前区最大值减最小值                          |
| blue_sum                    | int32  | 是   | 后区号码和值                                |
| blue_span                   | int32  | 是   | 后区最大值减最小值                          |
| red_odd_count               | int32  | 是   | 前区奇数数量                                |
| red_even_count              | int32  | 是   | 前区偶数数量                                |
| blue_odd_count              | int32  | 是   | 后区奇数数量                                |
| blue_even_count             | int32  | 是   | 后区偶数数量                                |
| red_zone_1_count            | int32  | 是   | 前区低区号码数量                            |
| red_zone_2_count            | int32  | 是   | 前区中区号码数量                            |
| red_zone_3_count            | int32  | 是   | 前区高区号码数量                            |
| red_consecutive_group_count | int32  | 是   | 前区连续号码组数量                          |
| red_max_consecutive_length  | int32  | 是   | 前区最长连续长度                            |
| year                        | int32  | 是   | 开奖年份                                    |
| month                       | int32  | 是   | 开奖月份                                    |
| day_of_week                 | int32  | 是   | 星期几（1-7）                               |
| draw_index                  | int32  | 是   | 按开奖时间排序后的序号                      |

## 2. prizes.parquet

`prizes.parquet` 保存大乐透每期开奖奖金等级信息

| 字段               | 类型    | 必填 | 说明                                                       |
| ------------------ | ------- | ---- | ---------------------------------------------------------- |
| issue              | string  | 是   | 开奖期号，例如 `26014`                                     |
| draw_date          | date32  | 是   | 开奖日期                                                   |
| rule_version       | string  | 是   | 奖级规则版本，用于标识不同历史阶段的奖级制度               |
| prize_rank         | int32   | 是   | 奖级序号，例如一等奖=1、二等奖=2                           |
| prize_name         | string  | 是   | 标准化奖级名称，例如：一等奖、二等奖                       |
| prize_event_type   | string  | 是   | 奖金事件类型，描述该条记录属于普通中奖、追加中奖或派奖事件 |
| prize_level_raw    | string  | 是   | raw 数据中的原始 `prizeLevel` 字段，用于数据追溯           |
| stake_amount       | float64 | 是   | 单注奖金金额，来源于接口 `stakeAmountFormat`               |
| stake_count        | int64   | 是   | 中奖注数                                                   |
| total_prize_amount | float64 | 是   | 总奖金金额                                                 |

### 字段特殊说明

#### rule_version

标识大乐透历史奖级制度版本。用于避免不同奖级制度之间直接比较造成统计偏差。

字典：

- v1
- v2
- v3
- v4

定义：

| 值  | 时间范围            | 规则说明                                             |
| --- | ------------------- | ---------------------------------------------------- |
| v1  | 上市起 ~ 14051 期   | 一等奖至八等奖；1 - 7 等奖支持追加；8 等奖仅基本     |
| v2  | 14052 期 ~ 19018 期 | 一等奖至六等奖；1 - 5 等奖支持追加；6 等奖仅基本     |
| v3  | 19019 期 ~ 26013 期 | 一等奖至九等奖；1 - 2 等奖支持追加；3 - 9 等奖仅基本 |
| v4  | 26014 期 ~ 至今     | 一等奖至七等奖；1 - 2 等奖支持追加；3 - 7 等奖仅基本 |

> 注意：如果大乐透官方奖级模式更改，后续增加版本与规则说明。

#### prize_rank

标准奖级编号。

字典：

- 1 = 一等奖
- 2 = 二等奖
- 3 = 三等奖
- 4 = 四等奖
- 5 = 五等奖
- 6 = 六等奖
- 7 = 七等奖
- 8 = 八等奖
- 9 = 九等奖

#### prize_name

标准化奖级名称。用于分析展示。

字典：

- 一等奖
- 二等奖
- 三等奖
- 四等奖
- 五等奖
- 六等奖
- 七等奖
- 八等奖
- 九等奖

#### prize_event_type

描述该条奖金记录代表的事件类型。

字典：

- `basic_prize`：普通基本投注中奖。对应 `一等奖`、`二等奖` 等。
- `additional_prize`：追加投注中奖。对应 `一等奖(追加)`、`二等奖(追加)`。
- `basic_bonus`：基本派奖事件。对应 `一等奖基本派奖`、`二等奖基本派奖`。
- `additional_bonus`：追加派奖事件。对应 `一等奖追加派奖`、`一等奖追加派奖`。
- `unknown`：未知事件类型。
